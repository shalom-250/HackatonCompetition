# Recruiter Command Center: User Guide 🏢

## 1. Mission Deployment (`/jobs/new`)
Deploy a new career node to the Umurava AI talent cloud.

### Required Modules:
- **Title & Level**: Standardized RDB tiers (e.g. 5.III).
- **Responsibilities**: Dynamic list of mission checkpoints.
- **Qualifications**: Degree and experience thresholds for AI matching.
- **Eval Matrix**: Selection of exams (Psychometric, Written, Oral, etc.).

## 2. Talent Intelligence (`/candidates`)
The Intelligence Matrix allows you to:
- View **AI-Ranked** applications sorted by Neural Score.
- Analyze candidate identity and referee endorsements.
- Filter candidates by mission node or score range.

## 3. Live Diagnostics (`/analytics`)
Real-time monitoring of your recruitment funnel, including:
- Total Job Nodes active.
- Candidate Injection Rate.
- Shortlisting Efficiency Metrics.
